# Векторный Конструктор Иллюстраций (Vector Illustration Assembler)

Веб-сервис на Python для автоматической и ручной сборки векторных композиций из библиотеки компонентов (главные и фоновые объекты) в различных форматах с поддержкой цветовых палитр и автоматического реколора (по аналогии с плагином Figma).

---

## Возможности сервиса

1. **Работа с векторной библиотекой SVG:**
   - 10 предустановленных компонентов в двух состояниях: **Главные** (цветные) и **Фоновые** (двухтоновый монохром).
   - Поддержка двух размеров детализации: **Размер L** (детальный) и **Размер S** (компактный с возможностью догрузки).
   - Загрузка новых SVG-иллюстраций в библиотеку через веб-интерфейс.

2. **Автоматизация сборки:**
   - **Сценарий 1 (По метафоре или заголовку):** Пользователь задает тему (например, *«Финансовая подушка безопасности»*, *«Учеба и экзамены»*, *«Музыка и фокус»*). Семантический движок анализирует смысл, подбирает главного героя, акцентные цветные объекты и монохромный фоновый контекст, формируя сбалансированную композицию.
   - **Сценарий 2 (По названию компонентов):** Пользователь указывает нужные компоненты (например, *«книга, лампа, ручка»*). Движок компоновки автоматически расставляет и масштабирует их по выбранному пресету (Центр-герой, Треугольный баланс, Динамическая диагональ, Журнальная асимметрия, Натюрморт).

3. **Цветовые палитры и автоматический реколор:**
   - Предустановлены 3 схемы из папки `цветовая палитра/`:
     - **Схема 1:** Сиреневая пастель (`цвета1.svg` + `фон1.svg`)
     - **Схема 2:** Персик и бирюза (`цвета2.svg` + `фон2.svg`)
     - **Схема 3:** Мята, ультрамарин и роза (`цвета3.svg` + `фон3.svg`)
   - Возможность **загрузки нового SVG-файла палитры** со свотчами и добавления произвольных схем.
   - Мгновенная перекраска всех элементов и фона холста в соответствии со слотами палитры.
   - Возможность переключения любого объекта между состояниями: **Главный (цветной)** ↔ **Фоновый (монохром)**.

4. **Интерактивный холст:**
   - Перемещение элементов мышью.
   - Вращение элементов (через маркер или слайдер).
   - Масштабирование с **строгим сохранением пропорций** (uniform scale).
   - Управление порядком слоёв: на передний/задний план, выше/ниже.
   - Дублирование и удаление объектов.
   - Выбор формата холста: 1:1 (Квадрат), 16:9 (Баннер), 4:3 (Презентация), 9:16 (Сториз), произвольный размер.
   - Выбор стиля фона: паттерн палитры, заливка цветом, белый, прозрачный.

5. **Экспорт:**
   - Скачивание чистого векторного SVG (полностью редактируется в Figma, Illustrator, Inkscape).
   - Быстрое копирование SVG-кода в буфер обмена для вставки прямо в Figma (`Ctrl+V`).

## Структура проекта

```
├── app.py                      # Основной сервер Tornado (REST API + статика)
├── engine/
│   ├── __init__.py
│   ├── library.py             # Индексация компонентов, L/S размеры, загрузка
│   ├── palette.py             # Парсинг палитр, реколор 1:1, фоновые паттерны
│   ├── semantic.py            # Семантический анализ метафор (Сценарий 1)
│   ├── layout.py              # Алгоритмы компоновки и пресеты расстановки
│   └── exporter.py            # Сборщик итогового чистого векторного SVG
├── static/
│   ├── index.html             # Веб-интерфейс
│   ├── css/style.css          # Стилизация (современная темная тема)
│   └── js/app.js              # Интерактивность холста и работа с API
├── tests/
│   └── test_service.py        # Набор юнит- и интеграционных тестов
├── главные объекты/           # 10 цветных векторных SVG (L)
├── фоновые объекты/           # 10 монохромных векторных SVG (L)
├── цветовая палитра/          # Файлы палитр и фонов (цвета1..3, фон1..3)
└── work.txt                   # Исходное техническое задание
```

---

## Запуск сервиса

Для запуска сервера выполните:

```bash
python3 app.py
```

Сервер запустится по адресу: **http://localhost:8080**

---

## Запуск тестов

Для запуска всех автоматических тестов:

```bash
python3 -m unittest discover -s tests
```
